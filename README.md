# Тестовое задание — Arkanoid

## Описание

Реализация игры Arkanoid на JavaScript с использованием библиотеки PixiJS.

## Реализованный функционал

1) управление платформой мышью
2) движение мяча и обработка столкновений
3) разрушаемые кирпичи
4) система очков
5) несколько уровней
6) надписи побед и поражений
7) автоматический переход между уровнями
8) режим 2 игроков
9) сохранение счёта
